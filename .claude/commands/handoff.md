Create a handoff document summarizing the current session's work. This will be used to reload context in the next session. Include:

1. **What was accomplished** — List of changes made, files modified, features added
2. **Current state** — Does the build pass? Any known issues? What branch are we on?
3. **What's in progress** — Any incomplete work, partial implementations, or open questions
4. **What was tried but didn't work** — Failed approaches, dead ends, important context
5. **Recommended next steps** — Prioritized list of what to do next
6. **Key decisions made** — Architecture choices, design decisions, trade-offs chosen

Write this to `CLAUDE.local.md` in the "Session Notes" section so it persists between sessions.
